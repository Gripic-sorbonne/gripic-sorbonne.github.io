# GRIPIC — Gestion du contenu du site web

Ce dépôt permet de gérer le contenu du site web du GRIPIC à l’aide de **GitHub Actions** et d’assurer sa publication via **GitHub Pages**.

Ce dépôt est un fork du projet original développé par CERES-Sorbonne, disponible ici : [CERES-Sorbonne/DefaultSite](https://github.com/CERES-Sorbonne/DefaultSite).
